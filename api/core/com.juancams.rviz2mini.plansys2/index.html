PlanSys2Messages
Link copied to clipboard
object PlanSys2Messages

PlanSys2's messages in their two shapes. The app has those of rolling (October 2026: plans with float64 times, the moments the effects were applied, the request of each action, the metric and constraints of the problem...), those of PlanSys2 4.0.0 (the Jazzy packages) and newer; the earlier releases (3.x and older) publish the earlier ones under the same DDS names. Without the size of the sample, which jros2 does not give, the shape is found by reading: the current one if its values make sense, if not the earlier one, which is then filled out to the current shape (its new fields with their defaults).
