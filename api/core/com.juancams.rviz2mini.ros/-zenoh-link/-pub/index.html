Pub

inner class Pub(val topic: String, val ddsType: String, qosKey: String, transientLocal: Boolean = false, reliable: Boolean = true, depth: Int = 1)

Publisher of a topic. The key expression carries the type hash, which the app does not compute: it is taken from the tokens of whoever already uses that topic with that type. Until someone uses it there is no one to send to and put returns false.
