RosNodes

object RosNodes

ROS 2 nodes on the network, like ros2 node list. DDS knows nothing about nodes: each rmw participant publishes on the DDS topic "ros_discovery_info" (no "rt" prefix) which nodes it has and the GIDs of their readers and writers. The latest from each participant is stored here; RosGraph cross-references it with the live endpoints (so participants that leave disappear).
