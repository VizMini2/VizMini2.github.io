TopicVariables

object TopicVariables

Variables in topic names, like those of Foxglove layouts: a topic ${ns}/scan is /robot1/scan with ns = /robot1. They are resolved when subscribing or publishing (RosConnection), so they apply to everything at once (RViz, plots, indicators, buttons...). Changing a variable reconnects so that everything uses the new name.
