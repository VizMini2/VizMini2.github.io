KnownRobots

object KnownRobots

Robots (machines running ROS 2) seen in each domain and their IPs. While multicast works they are learned automatically; afterwards they are used as unicast peers when connecting, so they are still found even if the Wi-Fi stops passing multicast. The logic is in Book (no Android, with tests).
