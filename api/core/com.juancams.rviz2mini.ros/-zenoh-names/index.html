ZenohNames

object ZenohNames

rmw_zenoh_cpp names (rmw_zenoh's docs/design.md): the data key expressions, the liveliness tokens with which each node, publisher, subscriber and service announces itself, and the ROS graph derived from those tokens. No Zenoh or Android dependencies, so it can be tested on the JVM.

graph
Link copied to clipboard
fun graph(tokens: Collection<ZenohNames.Token>, ownName: String? = null): RosGraph

ROS graph (the same model as with DDS) from the tokens: each session+node is a "participant" with a synthetic GUID starting with VENDOR_HEX (so the node's DDS shows as "Zenoh"), and its endpoints carry the usual DDS names ("rt/x", "rq/xRequest", "rr/xReply") so that lists, searches and actions work the same.
