RosConnection

object RosConnection

Single ROS 2 connection for the whole app. All tabs share the same DDS node: this way the configuration (domain id...) applies to all of them and there is no participant per tab.

Opening/closing the node is serialized on its own thread (creating a DDS participant can take time and must not block the UI). Each (re)connection increments generation; callbacks from previous nodes are discarded by comparing it.
