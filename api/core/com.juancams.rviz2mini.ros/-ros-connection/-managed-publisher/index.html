ManagedPublisher

class ManagedPublisher<T : ROS2Message<T>>(val topicName: String, val type: Class<T>, val qos: ROS2QoSProfile, val ddsName: String? = null)

Publisher that recreates itself after each reconnection. publish must always be called from the same thread (jros2's ROS2Publisher reuses a write buffer).

publish
Link copied to clipboard
fun publish(msg: T): Boolean

Returns false if there is no connection yet. One publication at a time: jros2 serializes under a lock but does the write outside it, over a shared native buffer, so two threads at once could send two copies of the same message (seen with concurrent calls to a service). It also makes publishing and reading the identity atomic in publishWithIdentity. The lock is the jros2 publisher itself, in case several share it.

publishWithIdentity
Link copied to clipboard
@Synchronized
fun publishWithIdentity(msg: T, identityOut: ByteArray, related: ByteArray? = null): Boolean

Like publish and additionally copies into identityOut (24 bytes) the DDS identity of the written sample: a service client needs it to recognize its response. related: the sample's related_sample_identity (24 bytes): a service reply carries its request's identity; a request, the GUID of the client's reply reader (as rmw_fastrtps does). False if it could not be written.
