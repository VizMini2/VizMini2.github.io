SeriesSpec

data class SeriesSpec(val id: String = UUID.randomUUID().toString(), val topic: String = "", val type: String = "", val field: String = "", val label: String = "", val color: Int = -1, val transform: SeriesTransform = SeriesTransform.NONE, val window: Int = 5, val scale: Double = 1.0, val offset: Double = 0.0, val formula: String = "", val script: String = "", val scriptGlobals: String = "", val inputs: String = "")

A series: the field field ("twist.twist.linear.x", "ranges-1", "status{name==motor}.level") of the messages on topic, or, if it has a formula, a series computed from others (Formula). After the transform, the value is multiplied by scale and offset is added.

Parameters

color

index into PlotSpecs.PALETTE; -1 = the next free one in the panel.
