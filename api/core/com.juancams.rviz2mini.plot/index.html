PanelKind
Link copied to clipboard
enum class PanelKind : Enum<PanelKind>

A panel shows its series over time, as XY (the first, x, against the second, y), as state transitions (STATES: one band per series that changes color with each value, like Foxglove's State Transitions panel; also works for texts), as a spectrum (FFT) or as a histogram of the values, these two with what is in the time window. sameScale: in XY, the same scale on both axes (for trajectories in meters). scatter: in XY, individual points instead of a line.
