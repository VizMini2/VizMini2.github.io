ButtonRunner
Link copied to clipboard
class ButtonRunner(val spec: ButtonSpec, registry: InterfaceRegistry, onState: (ButtonState) -> Unit)

Runs a button: creates its publishers / clients when constructed (so DDS has already matched them when it is pressed) and closes them in close. Closing with cancelRunning cancels the action in progress; without it (the screen is recreated on rotation) it only stops waiting for its result. Each button has its own thread: a call to a slow service does not block the others. onState is called on the main thread.
