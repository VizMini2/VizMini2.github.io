ButtonSpec

data class ButtonSpec(val id: String = UUID.randomUUID().toString(), val label: String = "", val kind: ButtonKind = ButtonKind.PUBLISH, val target: String = "", val type: String = "", val values: String = "{}", val color: Int = 0, val qos: QosPreset = QosPreset.RELIABLE, val repeatHz: Double = 0.0, val stopOnRelease: Boolean = true, val timeoutS: Double = 5.0, val confirm: Boolean = false, val definitions: Map<String, String> = emptyMap())

A button in the "Buttons" tab.

Parameters

target

name of the topic, service or action ("/cmd_vel").

type

full interface ("geometry_msgs/msg/Twist", "std_srvs/srv/SetBool"...).

values

JSON with the fields of the message / request / goal; anything missing uses its default.

repeatHz

publish only: if > 0 it publishes at that rate while held down.

stopOnRelease

with repetition: on release it publishes the message once with the numbers zeroed (release = stop, like a dead man's switch). Yes by default, also for buttons saved without the field.

timeoutS

service: maximum time to wait for the response; action: for the acceptance.

confirm

asks for confirmation before sending.

definitions

custom (non-built-in) definitions used by the type, so the button works the same when loaded on another phone from a profile.
