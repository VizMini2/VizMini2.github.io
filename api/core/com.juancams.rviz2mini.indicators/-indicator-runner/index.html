IndicatorRunner

class IndicatorRunner(val spec: IndicatorSpec, registry: InterfaceRegistry)

An indicator's subscription. Keeps only the latest (the field value or, for a table, its rows) and when it arrived; the UI reads it at its own pace with latest. Messages arrive on the DDS thread.
