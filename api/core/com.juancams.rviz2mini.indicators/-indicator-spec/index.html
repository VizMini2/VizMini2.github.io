IndicatorSpec

data class IndicatorSpec(val id: String = UUID.randomUUID().toString(), val label: String = "", val topic: String = "", val type: String = "", val field: String = "", val kind: IndicatorKind = IndicatorKind.NUMBER, val min: Double = 0.0, val max: Double = 100.0, val decimals: Int = -1, val unit: String = "", val rule: LightRule = LightRule.NONZERO, val threshold: String = "", val onColor: Int = 2, val offColor: Int = 6, val color: Int = 0, val qos: QosPreset = QosPreset.SENSOR, val timeoutS: Double = 0.0, val definitions: Map<String, String> = emptyMap())

An indicator in the "Indicators" tab: subscribes to topic (type type) and shows the field field ("battery.percentage", "ranges0", "" = the whole message in a table).

Parameters

decimals

decimals of the value; -1 = based on the field type.

timeoutS

if more seconds pass without messages, the indicator is marked as having no data (0 = never).

definitions

own definitions used by the type (to load it on another phone).
