GraphAccess

class GraphAccess

Access to the jros2 native pointers needed by the fastddsjavaGraph functions (added in the VizMini2/jros2 fork, see tools/jros2-16k): a node's participant, a publisher's DataWriter, a subscription's DataReader and the native SampleInfo. It lives in the jros2 package to read the protected fields; the DataWriter and the DataReader are private and are read via reflection (review when updating jros2).
