DashboardGrid

object DashboardGrid

Dashboard grid (no Android): 12 columns, square rows, infinite downwards. When moving or resizing a widget, the ones it collides with move down and then everything moves up as far as it can (like web dashboards), so there are never overlaps or gaps at the top.

Floating widgets (Item.floating) are separate: they go wherever they are dropped, on top of the others, and neither push nor get pushed (a joystick over the RViz, a small camera in a corner...).
