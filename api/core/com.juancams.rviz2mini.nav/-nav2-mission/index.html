Nav2Mission

class Nav2Mission(registry: InterfaceRegistry, onChanged: () -> Unit = {})

A Nav2 waypoint route (like RViz's Nav2 panel): waypoints are placed in the 3D view and sent with the FollowWaypoints action (stops at each one) or NavigateThroughPoses (passes through them without stopping). While running, the status: which one it is on, remaining distance and time, recoveries; when done, how it ended. It also listens to the navigate_to_pose status, so the regular Goal tool also shows progress. No Android or Filament.

Changes are notified with onChanged on the main thread.
