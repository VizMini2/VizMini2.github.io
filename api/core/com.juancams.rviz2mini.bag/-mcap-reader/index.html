fun messages(startNs: Long = Long.MIN_VALUE, endNs: Long = Long.MAX_VALUE, channelIds: Set<Int>? = null): Sequence<McapMessage>

Messages with startNs <= log_time <= endNs (and from channelIds, if given) in log_time order; on ties, in file order. Only keeps in memory the chunks that overlap in time with the current message. Can be iterated several times.
