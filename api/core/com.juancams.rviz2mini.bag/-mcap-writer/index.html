McapWriter

class McapWriter(out: OutputStream, chunkSize: Int = DEFAULT_CHUNK_SIZE, profile: String = "ros2", library: String = "vizmini2", rosDistro: String? = "jazzy", fileName: String = "vizmini2_0.mcap") : Closeable

Writes an MCAP file in streaming fashion, as rosbag2 (Jazzy) does with -s mcap: header with "ros2" profile, messages grouped in uncompressed chunks (~1 MiB) followed by their MessageIndex, and on close a summary with Schema, Channel, Statistics, ChunkIndex and MetadataIndex plus their SummaryOffset and the Footer. This way ros2 bag info / ros2 bag play read it without scanning the file.

Computes the CRC32 of each chunk, of the data section and of the summary. Not thread-safe: whoever records from several threads must synchronize the calls.

Schema and channel ids start at 1 (schema 0 means "no schema").

If rosDistro is not null, on close it adds the "rosbag2" Metadata record with the serialized_metadata that rosbag2 writes (so ros2 bag info shows the distro). fileName is only used for that YAML (relative_file_paths).
