ControlMsgs

enum class ControlMsgs : Enum<ControlMsgs>

The controller_manager_msgs versions with a different wire format (the app bundles Lyrical's, which Kilted and Rolling share):

  • Jazzy: HardwareComponentState with class_type (between rw_rate and plugin_name).

  • Humble: ControllerState without is_async, update_rate or exported_state_interfaces; SwitchController with the old start_controllers/stop_controllers beside the new ones, and only ok in the reply; HardwareComponentState and HardwareInterface shorter.

  • Foxy: ControllerState with only name, state, type and claimed interfaces; SwitchController with only start/stop; HardwareInterface with only name and is_claimed; no hardware components service.
