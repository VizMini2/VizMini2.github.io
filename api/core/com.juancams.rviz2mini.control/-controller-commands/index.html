ControllerCommands

object ControllerCommands

Moving the joints of a controller: a joint trajectory controller takes a trajectory_msgs/JointTrajectory on <controller>/joint_trajectory; a forward command controller (and the position/velocity/effort JointGroup ones) takes one value per joint, a std_msgs/Float64MultiArray on <controller>/commands.
