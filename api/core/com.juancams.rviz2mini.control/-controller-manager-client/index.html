ControllerManagerClient

class ControllerManagerClient(registry: InterfaceRegistry, manager: String = DEFAULT_MANAGER)

A ros2_control controller manager (like ros2 control): its controllers and their state, switching them on and off, loading, configuring and unloading them, and its hardware components and interfaces.

Foxy, Humble, Jazzy and Kilted/Lyrical speak different controller_manager_msgs (ControlMsgs): with AUTO the version is found from the first non-empty controller list (a reply in another format either cannot be read, and is dropped, or reads as nonsense, which plausible rejects).

The calls block: run them off the main thread. manager: the node name ("/controller_manager").
