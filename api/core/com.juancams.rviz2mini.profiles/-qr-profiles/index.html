QrProfiles

object QrProfiles

Profiles in QR codes: the profile JSON compressed (deflate) and in Base64 URL, with a prefix to recognize it ("R2M1:"). It can carry the full profile or just the connection (domain, node, peers, server), which always fits and works as a "sticker" on the robot. No Android: tested on the JVM.
