Srdf

class Srdf(val robot: String, val groups: List<Srdf.Group>, val states: List<Srdf.GroupState>)

What is needed from the MoveIt SRDF (/robot_description_semantic): the planning groups and their named states ("ready", "open"...). Each group's joints are obtained with the URDF (groupJoints): a group can be given by chain (base → tip), by links, by joints or by other groups.
