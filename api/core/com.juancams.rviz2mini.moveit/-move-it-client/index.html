MoveItClient

class MoveItClient(registry: InterfaceRegistry, val ns: String = "", onChanged: () -> Unit = {})

The MoveIt panel (like RViz's "Motion Planning", simplified): the robot and its groups come from /robot_description and /robot_description_semantic, the current position from /joint_states, and the goal is given in joints (sliders or a named state from the SRDF). It plans with the MoveGroup action (/move_action), executes the plan with ExecuteTrajectory (/execute_trajectory) or does both at once. move_group publishes the plan on /display_planned_path, which the 3D Trajectory display shows as a ghost robot.

ns: the move_group namespace ("" normally). Changes are reported through onChanged on the main thread.
