SliderSpec

data class SliderSpec(val id: String = UUID.randomUUID().toString(), val label: String = "", val target: String = "", val type: String = "", val field: String = "", val min: Double = 0.0, val max: Double = 1.0, val step: Double = 0.0, val initial: Double = 0.0, val mode: SliderMode = SliderMode.WHILE_DRAGGING, val rateHz: Double = 10.0, val springBack: Boolean = false, val values: String = "{}", val color: Int = 0, val definitions: Map<String, String> = emptyMap())

A slider in the "Sliders" tab: publishes on target a message of type with the numeric field field ("data", "linear.x") set to the chosen value and the rest from values, like a button.

Parameters

step

0 = continuous; otherwise the value snaps to min + k·step.

springBack

on release it returns to initial and publishes it (velocities: release = stop).

rateHz

publications per second while dragging (also with the finger still).

definitions

custom definitions used by the type (to load it on another phone).
