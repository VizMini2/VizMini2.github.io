SliderRunner
Link copied to clipboard
class SliderRunner(val spec: SliderSpec, registry: InterfaceRegistry, onState: (SliderState) -> Unit)

Publishes a slider. The publisher is created on construction (so DDS has already matched it when it moves) and closed in close. Everything is published from a single dedicated thread (the jros2 publisher does not support several). onState is called on the main thread.
