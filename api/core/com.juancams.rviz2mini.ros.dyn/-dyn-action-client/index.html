fun run(goal: MsgValue, acceptTimeoutMs: Long, onAccepted: () -> Unit, onFeedback: (MsgValue) -> Unit, cancelRequested: () -> Boolean, abandoned: () -> Boolean = { false }, cancelIfAbandoned: () -> Boolean = { false }): DynActionClient.Outcome

Sends the goal and waits for the result (blocking). Meanwhile it calls onAccepted and onFeedback (on the DDS thread). If cancelRequested becomes true, cancellation is requested and it keeps waiting for the result (it will arrive as CANCELED). If abandoned becomes true it stops waiting; the goal is only cancelled if cancelIfAbandoned is also set (otherwise the robot carries on with it).
