DynSlots

class DynSlots

"Slot" classes for dynamic messages. jros2 takes the DDS type from the public static field `name` of the message class, so each dynamic type needs its own class: DynTypes assigns one per DDS type and sets `name` at runtime. They are not reused. Generated (128 slots); to extend, add more identical lines and add them to ALL.
