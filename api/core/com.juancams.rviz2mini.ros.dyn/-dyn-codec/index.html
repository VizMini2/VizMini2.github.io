DynCodec

object DynCodec

Dynamic messages: a message is a LinkedHashMap<String, Any?> in .msg order with Boolean (bool), Long (integers; uint64 keeps the bits), Double (float32/64), String, lists (arrays) and nested maps (submessages).

Serializes to CDR (XCDR1, little endian) just like jros2's generated classes and rmw_fastrtps. Strings are written and read as real UTF-8 (jros2 truncates them to one byte per character).
