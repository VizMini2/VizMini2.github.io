fun withCycloneHeader(): MsgSpec

The same request or reply as sent by rmw_cyclonedds_cpp: with a 16-byte header in front (the client's uint64 guid and the call's int64 seq, in the encapsulation byte order). In CDR it is the same as two leading fields, and since it is 16 bytes the rest keeps its alignment. Same DDS type.
