DynServiceClient

class DynServiceClient(name: String, val srv: SrvSpec)

Client of a ROS 2 service: writes to "rqRequest" and reads "rrReply".

With an rmw_cyclonedds_cpp server, requests and responses carry their own header in front (client guid and call number) instead of the DDS identity: this is detected from the vendor of the server's request reader, and a separate channel with that header is used (CycloneChannel).

Each response is matched to its request as rmw does: the server writes it with the request's DDS identity as "related sample identity" (natives from the jros2 fork), so responses to other clients of the same service are ignored. Supports several calls at once: each one waits only for the response with its identity.
