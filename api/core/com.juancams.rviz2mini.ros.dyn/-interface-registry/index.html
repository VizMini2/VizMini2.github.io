InterfaceRegistry

class InterfaceRegistry

Interface definitions (.msg/.srv/.action) by full name ("pkg/msg/Name"). The built-in ones come from assets/ros_interfaces.txt (tools/gen_ros_interfaces.py); the user can add their own. Resolves nested types and caches what is already resolved.
