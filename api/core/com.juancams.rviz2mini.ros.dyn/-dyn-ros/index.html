DynRos

object DynRos

Publishers and subscriptions of dynamic messages over RosConnection (recreated automatically on reconnect).

The DynSlots classes only exist at runtime: everything that touches the generic type goes in generic functions so Kotlin does not insert casts to a concrete class.
