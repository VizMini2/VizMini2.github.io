Alert rules, without Android: they decide when to notify based on what arrives from the network. Each tracker remembers the previous state and only notifies on changes (and does not repeat the same notice within cooldownMs).

class TopicRuleTracker(val rule: TopicRule, cooldownMs: Long)

When a rule fires: on the change (the condition becoming true, or the topic falling silent), not on every message; and again, as RECOVERED, when it stops holding. cooldownMs: no new notice for the same rule before that.
