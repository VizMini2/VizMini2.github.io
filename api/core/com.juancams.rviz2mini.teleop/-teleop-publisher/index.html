TeleopPublisher

class TeleopPublisher(val settings: TeleopSettings, listener: (TeleopPublisher.State) -> Unit)

Publishes the joystick command at a fixed rate on its own thread. The logic of when to publish is in TeleopController; here the loop is scheduled, the messages are filled and the connection is watched (automatic stop if it is lost while driving).
