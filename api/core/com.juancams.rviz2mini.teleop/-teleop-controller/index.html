TeleopController

class TeleopController(stopRepeats: Int = 3, watchdogMs: Long = 500)

Decides what to publish on each tick (at a fixed rate). No threads or Android: testable.

  • With the finger on the joystick the current velocity is published on every tick.

  • On release, on pressing STOP or on hiding the tab, stopRepeats zeros are published and then nothing, so as not to fight other cmd_vel sources (Nav2, physical joystick...).

  • After a STOP the joystick is ignored until it is released and touched again.

  • Watchdog: if while driving the UI stops giving signs of life (heartbeat) for watchdogMs, it stops and locks like a STOP (frozen app, screen off...).
