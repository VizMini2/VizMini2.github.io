NavMapModel
Link copied to clipboard
object NavMapModel

EasyNavigation's NavMap (https://github.com/EasyNavigation/NavMap) as the NavMap display reads it: a navigable surface of triangles (NavCels), possibly on several floors, with per-cell layers and links between cells that do not share an edge (stairs, elevators, doors). Reads navmap_ros_interfaces/NavMap and NavMapLayer (as decoded by DynCodec), applies the layer updates and gives each cell (or vertex) its color. No rendering here: plain JVM, unit tested.
