Groot2

object Groot2

The Groot2 protocol (BT::Groot2Publisher, BehaviorTree.CPP 4.x): ZeroMQ REQ/REP requests to its port (1667 by default). Each request starts with a 6-byte header (protocol, type, random id) and the reply repeats that header followed by the tree UUID (16 bytes).
