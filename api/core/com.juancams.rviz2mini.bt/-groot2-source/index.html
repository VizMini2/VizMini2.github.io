Groot2Source

class Groot2Source(val host: String, val port: Int, periodMs: Long = 100) : BtSource

BehaviorTree.CPP 4.x Groot2Publisher: requests the tree (FULLTREE) and then the statuses (STATUS) every periodMs; if the tree UUID changes (another tree loaded) it requests it again. Status changes are deduced by comparing one query with the previous one. Reconnects by itself.
