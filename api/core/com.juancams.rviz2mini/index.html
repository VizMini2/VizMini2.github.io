LiveView
Link copied to clipboard
object LiveView

Freeze everything shown live at once (the dashboard's pause button): the 3D view stops applying new messages, and the plots, camera and diagnostics stay still. Messages keep arriving; on resume the latest is shown. With a bag playing, the pause is the bag's (see the playback bar).

TfMath

object TfMath

Rigid-transform math in double precision. 4x4 column-major matrices (same layout as OpenGL / Filament): mcol * 4 + row. No Android dependencies so it can be tested on the JVM.

TfTree
Link copied to clipboard
class TfTree

TF tree. update is called from the DDS thread; compute/poseInFixed from the render thread. Each frame stores its local transform relative to its parent; every compute resolves the global ones (relative to the root of its tree), detecting cycles and disconnected trees.
