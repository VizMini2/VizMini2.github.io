NodeGraphLayout

class NodeGraphLayout(measure: (String) -> Float = { it.length * 7f }, val nodeHeight: Float = 34.0f, val topicHeight: Float = 28.0f, val padX: Float = 12.0f, val layerGap: Float = 70.0f, val vGap: Float = 14.0f)

Layout of the bipartite nodes/topics graph (like rqt_graph "Nodes/Topics (all)"), in layers from left to right. Pure, deterministic Kotlin (same inputs -> same output).

Simplified Sugiyama:

  1. Cycle breaking with a deterministic DFS (back edges are reversed only to compute layers; they are drawn with their real direction).

  2. Layers by longest path from the sources; sources are moved closer to their successors.

  3. Ordering within each layer with several barycenter passes (down and up).

  4. Coordinates: X by layer; Y towards the mean of the already placed neighbors, without overlaps.
