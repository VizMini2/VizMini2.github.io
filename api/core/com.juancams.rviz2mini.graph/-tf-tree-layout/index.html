TfTreeLayout

class TfTreeLayout(measure: (String) -> Float = { it.length * 8f + 16f }, val boxHeight: Float = 36.0f, val minBoxWidth: Float = 48.0f, val hGap: Float = 16.0f, val vGap: Float = 40.0f, val treeGap: Float = 40.0f, siblingOrder: Comparator<String> = naturalOrder())

Top-down layout of the TF tree (like rqt_tf_tree / view_frames). Pure Kotlin, no Android, so it can be tested on the JVM.

Algorithm: post-order width allocation. Each subtree takes max(width of its box, sum of the child subtrees + gaps); the parent is centered over its children. This way siblings never overlap. Multiple roots (a forest) are placed side by side. Cycles (corrupt data) are cut: an already visited frame is not expanded again.
