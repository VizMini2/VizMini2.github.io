CompressedDepth
Link copied to clipboard
object CompressedDepth

Depth images from compressed_depth_image_transport ("…/compressedDepth"): a 12-byte header (format and two quantization parameters) and a 16-bit grayscale PNG, or with RVL the width, height and the RVL-compressed values (Wilson, 2017). In 16UC1 the PNG carries the millimeters as is; in 32FC1, the quantized inverse depth: z = a / (v - b) (v = 0: no data). No Android: tested on the JVM.

OverlayLayout

object OverlayLayout

Where an image panel (Image or Camera display) sits on top of the 3D view. By default it hugs a corner; once the user drags it, it keeps its own position as fractions of the view (x, y of its top-left corner, so it survives window resizes). The width is a fraction of the view width and the height follows the image aspect ratio.

class UrdfKinematics(val model: UrdfModel)

Forward kinematics of a URDF: where each link ends up (relative to the root link) for some joint positions. Revolute/continuous rotate about their axis, prismatic translates, fixed does not move and mimic joints copy theirs. For the ghost robot of a trajectory (MoveIt) without depending on the real robot's TF.
