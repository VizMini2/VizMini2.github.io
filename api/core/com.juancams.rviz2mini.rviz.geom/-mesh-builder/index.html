MeshBuilder

class MeshBuilder

Builds geometry in a frame's coordinates. Applies the current transform (push/pop) to every vertex and gives a fixed per-face shading (directional light "painted" into the color) so that solids look 3D with an unlit material.

Triangles with alpha < 255 go to a separate list (transparent material).
