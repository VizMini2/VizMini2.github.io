MiniYaml

object MiniYaml

Minimal YAML, enough for the .rviz files RViz 2 saves: block maps and lists by indentation, plain or quoted scalars, empty {}/[], ~ and comments. Maps preserve order. Scalars are always returned as String (or null for ~/empty).

RvizExporter
Link copied to clipboard
object RvizExporter

An RViz view of the app as an RViz 2 .rviz file (the reverse of RvizImporter): the displays with their rviz_default_plugins class, the topic with its QoS and its main properties, the Global Options, the tools and the current view. It can be opened with rviz2 -d file.rviz and imported back here.
