CameraStream

class CameraStream(val topic: ImageTopic, listener: CameraStream.Listener, qosProfile: ROS2QoSProfile? = null)

Subscription to an image topic. Decodes on the DDS thread and delivers bitmaps on the main thread. If the UI has not painted the previous frame yet, the new one is dropped (the most recent is always shown without accumulating delay).
