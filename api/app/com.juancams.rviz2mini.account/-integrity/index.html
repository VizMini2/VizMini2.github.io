Integrity

object Integrity

Checks that the APK is signed with our key. If someone decompiles it, modifies it and repackages it, they have to sign it with another key (they do not have ours), so the SHA-256 of the certificate changes and the app refuses to start.

It is not foolproof (a determined attacker can patch this very check, already obfuscated), but together with R8 obfuscation it raises the bar considerably.

The expected SHA-256 is injected by Gradle into BuildConfig, read from the release keystore. In debug it is empty and nothing is checked.
