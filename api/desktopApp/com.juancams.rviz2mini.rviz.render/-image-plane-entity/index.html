ImagePlaneEntity

class ImagePlaneEntity(engine: Engine, scene: Scene, material: Material, layer: Int, priority: Int = 0) : RenderEntity

A camera image on a quad (corners: the corners of pixels (0,0), (w,0), (w,h) and (0,h), in the entity's frame) for the Camera display background: it goes on its own layer (only the camera view sees it) and with a depthless material that is drawn first, so everything else in the scene stays in front.
