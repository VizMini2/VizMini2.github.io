InteractiveMarkersDisplay

class InteractiveMarkersDisplay(host: DisplayHost, config: DisplayConfig) : Display

"InteractiveMarkers" display (like RViz2's): subscribes to <ns>/update, requests the initial state from <ns>/get_interactive_markers and draws the controls. With the view's "Interact" tool, pick picks a control under the finger and the feedback functions publish on <ns>/feedback the clicks, menus and poses while dragging.

The display topic is the update one ("/basic_controls/update"); the namespace is what comes before it.
