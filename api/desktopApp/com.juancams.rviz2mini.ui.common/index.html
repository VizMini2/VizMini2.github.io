MessageFormState
Link copied to clipboard
class MessageFormState(val spec: MsgSpec?, values: JSONObject = JSONObject())

Form generated from the structure of a message (buttons, sliders, calling a service, sending a goal): one row per field, with submessages as indented sections. Arrays of numbers or text are typed comma-separated and arrays of messages as JSON. builtin_interfaces/Time fields have "current time" (it is saved as "now" and filled in when sending). The state lives here; MessageFormView draws it.
