FoxgloveLayout

object FoxgloveLayout

Foxglove layouts, in both forms: the JSON of "Export layout" (also Lichtblick's), with configById holding each panel's settings ("Plot!abc123": {...}) and layout, a tree of splits ({first, second, direction: row|column, splitPercentage}); and the newer programmatic one of the Foxglove SDK (version, content: panels, splits with proportions, tabs and stacks). A layout becomes a dashboard with a widget per panel, placed where the splits put it; exporting writes the first form, which the Foxglove app imports.
