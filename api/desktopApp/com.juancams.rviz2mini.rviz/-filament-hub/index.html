FilamentHub

object FilamentHub

Filament engine and GPU resources shared by all RViz tabs (materials, axes and grid geometry). Reference-counted; UI thread only.

Compiling the materials with filamat takes 5-10 s on a phone: it is done only once on a separate thread (prepare) and the binaries are saved to disk, so acquire only loads them (ms).
