RvizInteract

class RvizInteract(scene: RvizScene, pxPerDp: Float = 1.0f, onMenu: (InteractiveMarkersDisplay, IMarker, IMControl, List<Pair<String, Int>>) -> Unit = { _, _, _, _ -> })

Interact tool (interactive markers) over an RvizScene, without the per-platform part: touching a control grabs it; dragging it moves or rotates the marker according to its type and sends feedback to the server (at 20 Hz); a tap without dragging is a button click or opens the control's menu (onMenu, which each platform shows). If the gesture does not land on a control, down returns false and the camera handles it.
