PanelGesture

class PanelGesture(scene: RvizScene, pxPerDp: Float = 1.0f)

Moving and resizing the Camera display panels drawn inside the 3D view (the same on the phone and on the PC): press on a panel and drag to move it; drag its bottom-right corner (or pinch, on the phone) to resize it. The position and width are saved in the display configuration when the gesture ends. Pixels of the 3D view, main thread.

RvizInteract
Link copied to clipboard
class RvizInteract(scene: RvizScene, pxPerDp: Float = 1.0f, onMenu: (InteractiveMarkersDisplay, IMarker, IMControl, List<Pair<String, Int>>) -> Unit = { _, _, _, _ -> })

Interact tool (interactive markers) over an RvizScene, without the per-platform part: touching a control grabs it; dragging it moves or rotates the marker according to its type and sends feedback to the server (at 20 Hz); a tap without dragging is a button click or opens the control's menu (onMenu, which each platform shows). If the gesture does not land on a control, down returns false and the camera handles it.

class RvizScene(val tabId: String, density: Float = 1.0f, val overlay: Any? = null, val androidContext: Any? = null, val viewCtl: ViewController = ViewController(), onStatusChanged: () -> Unit = {}) : DisplayHost

The 3D scene of an RViz tab without the platform-specific parts (the surface it is drawn on and the gestures): Filament (renderer, scene, view and camera), the displays with their configuration saved in the tab, the fixed frame, the camera (ViewController) and the texts. Main thread. Requires FilamentHub.isPrepared.
