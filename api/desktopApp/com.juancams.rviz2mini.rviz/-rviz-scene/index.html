RvizScene

class RvizScene(val tabId: String, density: Float = 1.0f, val overlay: Any? = null, val androidContext: Any? = null, val viewCtl: ViewController = ViewController(), onStatusChanged: () -> Unit = {}) : DisplayHost

The 3D scene of an RViz tab without the platform-specific parts (the surface it is drawn on and the gestures): Filament (renderer, scene, view and camera), the displays with their configuration saved in the tab, the fixed frame, the camera (ViewController) and the texts. Main thread. Requires FilamentHub.isPrepared.

density: pixels per dp (fixed on-screen text size). onStatusChanged: some display changed state.
