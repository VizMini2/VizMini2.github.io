RvizTools

class RvizTools(scene: RvizScene, pxPerDp: Float = 1.0f, onMessage: (String) -> Unit = {})

The tools over an RvizScene, without the per-platform part: touches arrive as down/move/up/ cancel in view pixels; notices ("sent to /goal_pose"...) go out through onMessage. Main thread. Interacting with interactive markers is not here (each platform handles it).
