DesktopRecorder

object DesktopRecorder

Records the app's window to an MP4 (dashboards and the 3D view, as they look): Skia's own picture of the window (Compose paints in software, so it does not depend on the desktop allowing screen capture, which Wayland does not for X11 apps) FPS times per second, encoded by the system's ffmpeg (H.264). Saved in ~/Videos/VizMini2.
