BehaviorTreeController

class BehaviorTreeController(val tabId: String, val openXml: (done: (String?) -> Unit) -> Unit? = FileDialogs.openText?.let { o -> { done -> o(listOf("xml"), done) } })

State of the "Behavior tree" tab (like Groot2 in monitor mode): the tree of a BT::Groot2Publisher with the live status of each node, or the nodes of Nav2's /behavior_tree_log. Below, the tapped node (type and ports), the latest status changes or the blackboard. openXml: pick the XML of the Nav2 tree (null = not possible).
