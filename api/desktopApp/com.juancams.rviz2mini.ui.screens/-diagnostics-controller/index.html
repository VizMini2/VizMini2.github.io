DiagnosticsController

class DiagnosticsController(val tabId: String)

Diagnostics: /rosout, /diagnostics, the echo of a topic and a simple plot of its numeric fields. The data is received on the DDS thread and read on refresh; kept outside Compose for the tests. Settings are stored in the tab with the same keys as before on Android.
