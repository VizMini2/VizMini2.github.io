PlotController

class PlotController(val tabId: String, platform: PlotPlatform = plotPlatform)

State and logic of the plots tab: up to PlotSpecs.MAX_PANELS panels with the same time axis and the same cursor, series from any topic with transformations, XY panels, CSV export and, instead of live, the data of an MCAP bag (or a CSV) with a timeline.

Everything on the main thread (Platform.main); bag reading on a separate thread. frame changes with every frame that has to be drawn. Between resume and pause the screen refreshes.
