GpsController

class GpsController(val tabId: String)

GPS tab (like Foxglove's Map panel): the positions from a sensor_msgs/NavSatFix topic on an OpenStreetMap street map, with the accuracy circle and the track. The map is panned with a finger or the mouse (which stops following), and zoomed with pinch, wheel or double tap.
